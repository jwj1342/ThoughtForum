# AC：Communicating Activations Between Language Model Agents

> `ramesh2025communicating` · ICML 2025（PMLR 267） · 2025-01-23（本地为 v2，2025-05-07） · [arXiv](https://arxiv.org/abs/2501.14082) · 代码：未开源（论文未给链接） · 本地 PDF：`pdf/2501.14082_AC.pdf`
> 精读：2026-10-15 · 读到的范围：正文全文；App. A（只有定性示例图的标题）；App. B.1–B.7（Table 5–10、Fig. 11）

## TL;DR
做法是暂停 receiver B 在第 j 层的前向，把 sender A 第 k 层**最后一个 token 的单个残差流向量**替换进 B 最后一个 token 的位置，然后 B 继续前向并解码。整个过程不需要训练。在信息不对称的协调游戏里（A、B 是同一个模型），这一个向量就足以传递事实：LLaMA-3.2-3B 的 Countries 从 silent 0.0 升到 78.0，NL 为 69.0，skyline 为 84.0（Table 2）。推理基准上的增益来源则很可疑：A、B 读的是同一道题，论文没有做任何错配向量或随机向量的对照。标题里的 “up to 27.0%” 实际上是 MMLU Formal Logic 上 47 对 37 的**相对**提升，每个数据集只有 100 题（Table 3）。

## 1. 问题与动机
- 自然语言辩论（NLD）的推理成本随 agent 数和轮数快速增长。采样一个 token 也会丢掉 logits 和中间层里的信息。作者引用 Hernandez et al. 2024 的观察：中间层有 “enriched entity representations”（§1、§3.3）。
- CIPHER 传的是概率加权的 embedding。作者认为它仍然有损失、不省算力，而且要求两边共享 tokenizer（§1、§4.2 Baselines）。
- 作者还想检验 1–70B 的小模型能否从“交流”中获益（§2）。

## 2. 方法
- **信道**：A 对 prompt 做部分前向，到第 k 层为止，取最后一个 token 的 post-layer 激活 a=(h_{A,k})_{t_A}∈R^{d_A}，**整条消息只有这一个向量**。B 前向到第 j 层，用 f(a,b) 替换自己最后一个 token 的激活 b，再从第 j+1 层继续前向并解码（§3.1）。后续生成的 token 只能通过这一个位置在第 j 层以上的 KV 受到影响。
- **融合函数**：f∈{sum, mean, replace}，主实验用 replace，k=j=26（Fig. 2 在协调游戏上对 (k,j)∈{1..30}² 做网格搜索）。
- **维度不等时**（脚注 1）：做纯**坐标拼接**。以 3B→8B 为例（3072→4096），replace 的结果是 B 的前 1024 维保留，后 3072 维换成 A 的全部坐标，中间没有任何语义对齐。
- **可选映射 W**：W∈R^{4096×3072}，约 1258 万参数（按维度计算）。用 C4 中 3072 句话的第 26 层末 token 激活做 MSE 回归，训练 10 epoch，batch 32，Adam，lr 1e-3（§3.1、§4.2）。作者称它“task-agnostic”，每个模型对只需训一次。
- **协议**：2 个 agent，单向，一次性传递，没有轮次。A 不生成任何文本，只做部分前向。B.5 给了同模型变体：A 先带温度采样一段回答，再取回答末 token 的激活。
- **算力分析**：§3.2 的 Eq.(1)/(2) 基于 Hoffmann et al. 的 FLOPs 公式，比较的是 NLD 的“生成 M token + B 读 P+M”与 AC 的“A 部分前向 + B 一次前向”。

## 3. 实验设置
- **协调游戏（§4.1）**：两个 Lewis 信号博弈。Countries 是 A 看到 “X is at the [地标]”，B 要回答国家，共 100 条合成样本。Tip Sheets 是 A 看到投资提示，B 要选公司，共 70 条。A 和 B 是同一个模型（LLaMA-3.2-3B 或 3.1-8B）。对比条件有 silent（✗）、SKYLINE（拼接两边 prompt）和 NL（A 写一条消息）。指标是 exact match，正文写的是 greedy 解码。
- **推理基准（§4.2）**：A=LLaMA-3.2-3B，B=LLaMA-3.1-8B，**两者读同一 prompt**。数据集有 Biographies、GSM8K 和 5 个 MMLU 子集，每个随机抽 100 题。Biographies 用 LLaMA-3.1-8B 当 judge。NLD 设为 2 agent、2 轮、多数票。解码写的是 nucleus p=0.9，与 §4.1 的 greedy 说法并存，没有解释。
- **跨家族（Table 4）**：Qwen-2.5-1.5B/3B、Gemma-2-2B/9B、LLaMA-3.2-3B/3.1-8B 两两组合，不用 W。
- **种子与算力**：种子数未报告，GPU 未报告。± 的含义没有说明：GSM8K 的 ±4.9 恰好等于 n=100 时的二项标准误，MMLU 主表却是 ±0.1、±0.8 这类数值。

## 4. 主要结果
- **协调游戏（Table 2）**：
  - 3B：Countries 为 ✗ 0.0 / SKYLINE 84.0 / NL 69.0 / sum 34.0 / mean 36.0 / replace 78.0；Tip Sheets 为 38.6 / 100 / 74.3 / 50.0 / 80.0 / 90.0。
  - 8B：Countries 为 2.0 / 86.0 / 77.0 / 71.0 / 70.0 / 83.0；Tip Sheets 为 54.3 / 100 / 85.7 / 85.7 / 92.9 / 95.7。
- **推理（Table 3，顺序为 3B / 8B / NLD / AC / AC(W)）**：
  - Biographies：79.4 / 83.9 / 80.2 / 84.6 / 86.8
  - GSM8K：58 / 60 / **75** / 64 / 66（AC 明显输给 NLD）
  - HS Psych：30 / 65 / 83 / 85 / 70
  - Formal Logic：16 / 42 / 37 / 47 / 35
  - College Bio：11 / 50 / 71 / 78 / 79
  - Prof. Law：0 / 20 / 30 / 30 / 45
  - Public Relations：26 / 53 / 63 / 74 / 63
- **跨家族（Table 4，Biog / GSM8K）**：
  - Gemma-2-2B→9B：B 单独 94.6/80，AC 88.1/90，Biographies 上**低于 B 单独**。
  - Qwen-1.5B→Gemma-2B：B 单独 83.0/45，AC 73.0/55。
  - LLaMA-3B→Gemma-2B：B 单独 83.0/45，AC 84.0/60。
- **全 MMLU（Table 10）**：AC 62.7±2.2，NLD 60.7±2.0，57 个子集中 48 个持平或更好。
- **增加辩论轮数（Table 9）**：NLD 在 GSM8K 上 3 轮达到 79，AC 仍是 64。

## 5. 消融与诊断
- **改哪些 token（Table 5）**：只改最后一个 token 最好。对所有 token 做 sum 会大幅下降，例如 HS Psych 从 85 掉到 35。
- **A 先做 CoT（Table 6）**：没有带来提升。
- **用 GSM8K 训练集学 W（Table 7）**：AC 从 64.0 升到 78.0。这说明 W 实际上依赖任务分布，与“task-agnostic”的说法矛盾。
- **相似度与增益（B.4，Fig. 11）**：6 个模型对上，激活空间相似度与 Biographies 增益正相关。只有 6 个点，证据很弱。
- **同模型（Table 8，两个 8B 实例）**：Public Relations 上 AC 79 对单模型 53；GSM8K 上 AC 60 等于单模型，NLD 为 70。
- **对调 A、B**：Biographies 81.5，GSM8K 61.0（§4.2）。

## 6. 批判性评估
- **声称 vs 实际支持**：
  - 协调游戏确实证明了**单向量可以传递 prompt 私有事实**。silent 是 0，B 不可能猜出地标所在的国家。这是本 batch 里最干净的“信息真的过去了”的证据，但只限于同一模型。
  - 推理基准没有信息不对称，“A 把权重里的知识传给 B”只是假说。
  - 标题的 27% 是相对值，而且 NLD 在 Logic 上本身低于 8B 单模型（37<42），AC 对 B 单独只多 5 个点。
  - “<1/4 compute” 是对 2×2 轮 NLD 的解析 FLOPs，不是等算力比较。
- **缺失的对照**：
  1. 错配消息（A 读另一道题时的激活）、范数匹配的高斯向量、置零、B 自己第 26 层的激活。跨家族时 AC 做的是无对齐的坐标硬拼接（Qwen 1536 维写进 Gemma 2304 维的后段），却仍有“增益”，所以这组对照尤其必要。
  2. 等算力基线，例如 B 的 self-consistency。
  3. 推理任务中“A 单轮 NL 消息→B”的对照。
- **可能的混杂因素**：
  - MMLU 单模型基线异常低：LLaMA-3.2-3B 在 Prof. Law 上 0.0、College Bio 上 11.0，8B 在 HS Psych 上 65。这强烈提示 exact-match 解析或格式失败。改动最后一个 token 可能只是“修好了输出格式”。
  - k=j=26 是在游戏测试集上选出来的。
  - Table 2 的 bootstrap CI 不可信：n=100 时给出 78.0 (77.7, 78.2)，宽度不到 1 pp，正常应在 ±8 pp 左右。
  - LLaMA-3.2-3B 与 3.1-8B 同源，论文没有讨论这种同源性对坐标对应的影响。

## 7. 局限
- **作者自述**：不用 W 时需要 embedding 空间大致对齐；需要白盒访问；可解释性差（§5）。
- **我们的判断**：
  - 带宽只有一个向量，只在 prompt 末位注入一次，没有多轮交流。
  - 推理任务的样本量（100）和统计报告都不足以支撑 SOTA 结论。
  - “跨家族有效”反而削弱了“内容被利用”的解释。

## 8. 可复现性
- 没有代码，但方法极简：在 HF 的 residual stream 上挂 hook 即可，一天内可以复现。
- 3B+8B 用 bf16 约 22 GB，单张 H100 完全够用，主结果可以复现。
- 缺失的信息：prompt 模板、答案解析规则、Biographies 的 judge prompt、种子，以及 ± 的定义。

## 9. 与本课题的关系
- AC 是“一个眼神”最字面的实现：一个 d 维向量替换掉一个 token 表征，文本监控完全看不到。
- Countries 游戏说明，同权重实例之间连对齐都不需要就能传事实。OpenAI–HF 事件中的 agent 正是同权重的，这暗示它们**若能互读激活**，可以绕开明文记事本。不过该事件里不存在激活通道。
- 研究方法上的教训：必须区分“有信息不对称的任务”和“同题共读的任务”。后者的增益可能来自扰动或格式效应。

## 10. 可以接着做的问题
1. **内容对照复现**（低难度、高价值）：用 LLaMA-3.2-3B→3.1-8B 和 Qwen2.5-1.5B→Gemma-2-2B 两组，在 MMLU 子集上改用 choice-logprob 评分以消除格式问题。设 5 种条件：匹配激活、他题激活、范数匹配高斯、置零、B 自身激活。预期是 MMLU 上匹配与他题差距接近 0，而 Countries 上差距很大。
2. **单向量容量曲线**：把 Countries 扩展到 A 的 prompt 含 1–32 条事实，对比三种消息：末 token 一个向量、末 m 个 token 的向量、m 个 token 的 NL 消息。扫描层 k，估计“每向量可传多少条事实”，预期在中后层出现饱和。
3. **跨家族对齐方式对比**：比较坐标拼接、C4 学的 W、闭式正交 Procrustes，以及随机正交旋转 a 作为负对照，检验跨家族“增益”是否会随对齐质量单调变化。
4. **监控可检测性**：用线性探针在 B 的激活上检测“是否被注入过消息”，再测 B 的输出文本能否被一个文本 monitor 识别出带有外来信息，以此量化这条隐蔽信道的可审计性。
