# ThoughtComm：Thought Communication in Multiagent Collaboration

> `zheng2025thought` · NeurIPS 2025（Spotlight，依据索引 venue_evidence） · 2025-10-23 · [arXiv](https://arxiv.org/abs/2510.20733) · 代码：未开源（论文没有给链接；索引记录了一个非官方复现 github.com/AUMEZAK/thoughtcomm，未核实） · 本地 PDF：`pdf/2510.20733_ThoughtComm.pdf`
> 精读：2026-10-15 · 读到的范围：正文全文；App. A（Thm 1–3 证明）、B、C.1–C.4；Table 1 与 Fig. 5/6 已对照 PDF 第 8–9 页核对

## TL;DR
论文把多个 agent 的 model state 拼接成 H_t，并假设 H_t=f(Z_t)，其中 f 可逆。在 Jacobian 稀疏和 ℓ0 正则的条件下，作者证明：任意两个 agent 的“共享思维块”和“私有思维块”彼此不会混合，Jacobian 支撑结构可以辨识到置换（Thm 1–3）。工程实现上，作者用 ℓ1-Jacobian 稀疏自编码器抽出 Ẑ，按 agent 的一致度加权，再经 adapter 变成**1 个前缀 token** 注入每个 agent，**文本辩论照常进行**。主结果中，Qwen3-1.7B 在 MATH 上从 Multiagent Finetuning 的 75.8 提升到 93.0（Table 1）。但论文**没有普通文本辩论基线，也没有任何前缀内容消融**，理论假设与 LLM 的实际情况相差很远。

## 1. 问题与动机
- 自然语言模糊、有损。作者引用 MAS 失败分析（Cemri et al. 2025），认为 agent 应该直接交换“思维”（telepathy）。
- 作者认为多 agent 场景中既有共享思维，也有私有思维，结构信息（谁持有哪些思维）本身对协作有用。
- 作者声称这是首个对 LLM agent 回答背后潜在生成过程给出可辨识性保证的工作（§3.4）。

## 2. 方法
- **信道**：每个 agent 取“上一轮最后生成 token 的表征”（§4.1）。论文**没有说明取哪一层**，按语境推测是末层。n_a 个 agent 的表征拼接成 H_t，经编码器得到 Ẑ_t∈R^{n_z}。对 agent i，只保留在 B(J_f̂) 中影响它那一段状态的维度，按 α_j（依赖该维的 agent 数）分组，乘以权重 w_α 后拼接，再由 adapter g 映射成前缀 P∈R^{m×d}，m=1（C.1）。前缀**拼接在下一轮输入 token embedding 之前**，即注入第 0 层。
- **对齐与映射**：只有同构设定，每组实验的所有 agent 用同一个 base model。可训练部分是 AE 和 adapter，参数量、结构、n_z（C.4 写的是 1024）、ℓ1 系数、w_α 取值都**没有给出**。训练数据是每个 benchmark 随机抽的 500 题（§5.2）。
- **训练目标**：
  - AE 的损失是 Eq.7：重建误差加 ‖J_f̂‖₁。
  - adapter 的损失是 Eq.12：让带前缀生成的 1 句话，在均值 embedding 上与“**无通信参考输出**”的余弦相近，再加上流畅度项。也就是说，目标里**没有任何项奖励 agent 利用思维内容**，反而惩罚前缀改变输出。
- **协议与拓扑**：沿用 Subramaniam et al. 2025，3 个 agent 辩论 2 轮。“surface-level messages are broadcast”（§4.2），所以文本消息全部保留，latent 前缀是额外附加的。
- **理论**：Thm 1 说共享块与其余变量的偏导为 0；Thm 2 说私有块与另一 agent 的全部变量的偏导为 0；Thm 3 说 B(J_f̂)=B(J_f)P。证明是 Zheng et al. 2022 式的 Jacobian 支撑论证，加上 Hall 婚配定理。

## 3. 实验设置
- **合成实验**：
  - 2 个观测、3 个潜变量块，潜变量是 Laplacian，经随机可逆变换生成观测，报告 R²（Fig. 3）。
  - 另有 8 个设定，维度 128–1024，潜变量与观测维数相等，报告 MCC（Fig. 4，读图约 0.88–0.91，高于 0.8 阈值）。
- **真实实验**：
  - benchmark 是 MATH（挑较难题，“e.g., level-3”）和 GSM8K，各 500 题训练、500 题测试。
  - 模型是 Qwen3-0.6B、Qwen3-1.7B、Phi-4-mini（3.84B）、LLaMA-3-8B-Instruct、DeepSeek-R1-Distill-Llama-8B。
  - 基线是 Single Answer 和 Multiagent Finetuning（MAFT，使用官方代码）。
  - 指标是准确率和一致率（consensus）。
- **统计与算力**：± 与 √(p(1−p)/500) 吻合（例如 45.80±2.23），是**二项标准误，不是多种子方差**。种子数没有报告。所有实验在 1 个 8×H100 节点上完成（C.1）。

## 4. 主要结果
- **Table 1（MATH 准确率 / GSM8K 准确率）**：

  | 模型 | Single | MAFT | ThoughtComm |
  |---|---|---|---|
  | Qwen3-0.6B | 45.8 / 58.2 | 71.2 / 70.8 | 85.0 / 75.8 |
  | Qwen3-1.7B | 43.6 / 67.4 | 75.8 / 84.2 | 93.0 / 85.0 |
  | Phi-4-mini | 63.8 / 81.6 | 60.2 / 82.16 | 74.6 / 84.2 |
  | LLaMA-3-8B | 36.2 / 60.8 | 39.68 / **69.2** | 45.6 / 68.4 |
  | R1-Distill-8B | 42.6 / 65.6 | 72.4 / 76.8 | 82.8 / 80.8 |

  LLaMA 的 GSM8K 准确率，以及 R1-Distill 的 MATH consensus（MAFT 82.87 对 ThoughtComm 80.72）都是 MAFT 更好，所以正文“consistently outperforms”的说法不成立。
- 作者给出的平均值：相对 Single 提升 67.23%，相对 MAFT 提升 19.06%（§5.2）。
- **轮数（Fig. 6）**：LLaMA-3-8B、2 个 agent、2–6 轮下，ThoughtComm 约 38–43，MAFT 从约 36 降到约 30（读图）。

## 5. 消融与诊断
- 只有超参扫描：
  - 前缀长度 m∈{1,4,8,16}，波动小于 5%（Fig. 5）。
  - 潜维 128–2048，在 512–1024 饱和（C.3）。
  - 轮数 2–6（Fig. 6/7）。
  - agent 数 2–5（C.4，Fig. 10）。
- **没有消融的部分**：稀疏正则、结构掩码、一致度加权、去掉 AE（直接把 H 送进 adapter）、随机或错配的 Ẑ。
- Fig. 5 显示 m 从 1 增到 16 几乎不影响结果，这本身提示**前缀内容可能影响很小**。

## 6. 批判性评估
- **声称 vs 实际支持**：
  - 可辨识性只在合成数据上验证过。论文没有检查在真实 LLM 上恢复的“思维”是否稳定、是否可辨识，例如不同 AE 种子之间结构是否一致。
  - “beyond language”与实际不符：文本辩论全部保留，latent 部分只有 1 个前缀 token。
  - Thm 3 只保证支撑结构可辨识到置换；Thm 1/2 只保证块与块之间不混合，块内可以任意可逆混合。正文所说“recover the content of each thought”属于过度解读。
- **缺失的对照**：
  1. **普通多 agent 辩论**（同样的 agent、同样的轮数、不加前缀）。这是决定性的缺口：MAFT 会微调整个模型，是完全不同的方法，ThoughtComm 的领先可能全部来自辩论本身或评测管线的差异。
  2. 用打乱题目或范数匹配的随机向量作前缀。
  3. 前缀只用本 agent 自己的 H（无通信）。
  4. 去掉结构掩码。
  5. 没有任何 token 或 FLOPs 的等算力比较。
- **可能的混杂因素**：
  - adapter 的训练目标本身会压制前缀效应。
  - Single Answer 对 Qwen3 是否开启 thinking 没有交代。
  - 只有一次运行。
  - MATH 的难度子集是人为挑选的。
- **可辨识性假设是否现实（本 batch 要求回答的问题）**：
  1. **f 确定且可逆、Z 连续且有密度**：LLM 的 hidden state 是离散 token 上下文的确定函数，并不存在外生的连续“思维”变量；可逆要求 n_z≤n_h，而且没有噪声。实践中 n_z=1024，远小于 3×d（LLaMA 是 12288），AE 是有损压缩，定理前提里的“分布等价”并不成立。
  2. **真实 Jacobian 在 agent 间稀疏**：3 个同权重副本读同一道题，题目内容几乎影响每个 agent 的状态，B(J_f) 应该接近稠密，“私有思维”可能为空集，定理就变得平凡。agent 之间的差别主要来自采样随机性，而模型里并没有对应的潜变量。
  3. **估计器达到 ℓ0 意义下的全局最优，且处于渐近样本**：实际只有 500 题、用 ℓ1 正则和有限步优化，与前提相差甚远。
  4. 每个“思维”是一个标量维度，用它解释“速度”“行李”这类语义因素是一种解释上的跳跃。
  5. 定理陈述没有显式要求潜变量相互独立，证明只用到支撑集论证。这一点相对宽松，算是理论的优点。
  - 结论：理论是一个关于**结构可辨识**的漂亮的非参数结果，但它与 LLM pipeline 之间几乎没有可检验的桥梁；实验增益不能归功于理论。

## 7. 局限
- **作者自述**：需要访问模型内部状态，闭源模型无法使用；可以改用文本 embedding 作为代理（App. B）。
- **我们的判断**：
  - 只有同构 agent，只在数学任务上测，只有一次运行。
  - 关键超参缺失。
  - Remark 1 称模块“task-agnostic，可复用”，但模块是在每个任务的 500 题上训练的，没有做跨任务测试。

## 8. 可复现性
- 没有官方代码，AE 和 adapter 的结构、正则系数、权重 w_α、取哪一层都没有给出，**无法忠实复现**，只能“按思路重做”。
- 算力很小：0.6B–8B 模型，3 个 agent 推理，加上一个处理约 1.2 万维输入的 AE。单张 H100 就能跑完主表。Jacobian ℓ1 正则需要逐样本求雅可比，开销中等。

## 9. 与本课题的关系
- 这是唯一一个从理论上定义“共享 vs 私有思维”的工作，正好对应“一个眼神”里的 common ground：眼神之所以能懂，是因为共享块大。
- 对 OpenAI–HF 事件中的同权重 agent，这个框架预测共享块会非常稠密、私有块很小，也就是说同权重 agent 天然高度“同心”。
- B(J) 结构可以反过来当作**合谋或协同的监测量**：如果两个本应独立的 agent 出现了新的共享潜因子，就可能是协调的信号。

## 10. 可以接着做的问题
1. **补最小对照**（低难度，灌水风险低但价值高）：在 Qwen3-1.7B、3 个 agent、2 轮、MATH 500 题上比较 5 个条件：(a) 普通文本辩论；(b) ThoughtComm；(c) 他题的 Ẑ 作前缀；(d) 范数匹配高斯前缀；(e) 不用结构掩码。如果 (a)≈(b)，说明增益来自辩论本身。
2. **真实 LLM 上的可辨识性检验**：用 5 个种子训练 AE，经 Hungarian 匹配后比较 B(J) 的 Hamming 距离和 MCC。再做植入式验证：给每个 agent 不同的私有事实，用探针检查“私有维”是否对应这些事实。预期在真实数据上结构不稳定。
3. **异构扩展**：把 Qwen3-1.7B 与 LLaMA-3.2-3B 的 H 拼接（理论并不要求同构），检验共享块是否对应题面共享内容、私有块是否对应模型特有的偏好。
4. **作监测器**：在 Schelling 式无消息协调任务里，用 B(J) 的变化检测“隐性共享因子”的出现，并与行为层面的合谋指标对照。
