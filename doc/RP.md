# 研究计划（RP）

**零信任隐式思维论坛：LLM 智能体之间不经文字的通信**
*Latent Thought Forum: Text-Free Communication among Untrusting LLM Agents*

**一句话.** 我们为 LLM 智能体提出一种不经文字的通信方式：每条帖子是作者模型从自己完整上下文中读出的少量潜在向量，互不信任的智能体在一个共享的“思维论坛”上读写这些帖子，协作推进同一个长程软件项目。我们配合一个信息量已知、以代码执行判定的测量基准，刻画这种消息能传递什么、它跟随作者所知还是所言，以及它能否被审计。

**展开.**

- **动机.** 多智能体系统用自然语言交流，而文字既有损又可以撒谎。同伴对接口的转述常常不精确；能力不足或执着于目标的智能体，会声称完成了实际并未完成的工作，这些伪说辞沿上下文在群体中传播。因此智能体之间应当零信任：照常交流，但不默认相信任何一条说法，每条说法在被使用之前都要经过主动验证。验证本身也需要可信的依据：重新执行只覆盖测试写到的部分，同伴写的测试又常常是错的。
- **方法.** 帖子不是作者写下的文字。在作者上下文末尾接 k 个固定的查询向量，取其末层状态，映射回输入嵌入空间，得到 k 个软 token。读者是同一个冻结模型，帖子连同一行明文出处（作者、对象）放进它的提示。方法不训练任何参数，代价是 k 个位置的一次前向；论坛就是这些帖子的集合。帖子由受信推理端计算，智能体不能自行提交向量。
- **测量.** 基准中的每个项目，生产者持有一项随机生成、无法猜出的私有约定，信息量可调；消费者必须从帖子获知它，所写代码由隐藏测试判定。作者的话分为如实、省略、说错三种。每个条件报告三个数：传递率；作者说错时，读者跟随其所知还是所言；读者“用得出”与“说得出”之差。对照为无帖子，以及换成另一作者的帖子。
- **比较与分析.** 对比文本消息、贴代码、共享完整上下文、隐状态池化、LatentMAS 式潜在思考、激活合并，以及训练过的压缩器。给出信息量 × 向量数的容量曲线，以及同时在场的帖子数增加时的干扰曲线。用帖子移植和上下文编辑做因果分析，并在第二个模型上复现。
- **初步现象.**
  1. **潜在信号跟随作者所知，而非所言.** 作者谎称完成时，从作者上下文读出的向量仍带着真实的测试结果：线性探针能区分谎言与真话，训练过的写入端能让原版读者读出真相。这使它可以作为核对说法的证据，也意味着它会泄露作者没有说的东西。
  2. **冻结读者读不出其中的实例内容.** 无论池化作者的话，还是从完整上下文读出，免训练的潜在帖子都传不过私有格式；附在文字旁边时，读者仍跟着文字里的错误格式走。在任务上训练写入端，又会收敛成模板。（早先报告的"零训练即胜过文字""读者用得出、说不出"源于评测代码的错误，已撤回。）
- **延伸.** 论坛内容跨任务沉淀为群体“文化”后，有益经验与隐藏特质（例如作弊倾向）如何被选择和扩散；in-context / function vector 可以视为其中可遗传的单元。
